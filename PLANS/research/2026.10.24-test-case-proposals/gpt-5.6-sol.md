## Five behaviors most likely to be missed

1. **P1-028 — Unlinked old result still enriches its originating call.**  
   Implementers are likely to conflate result-to-call pairing with call-to-transcript linkage. A missing `agentId` or unresolved transcript must not erase known outcome and usage.

2. **P1-037 — Meta-only changes invalidate both graph and enriched detail.**  
   A conventional transcript-mtime cache stays green in basic tests while serving stale `subagent_ref` data indefinitely.

3. **P1-046 — Agent ID participates in every cache key.**  
   Reusing existing session/message keys can cause silent cross-agent transcript contamination when message UUIDs collide.

4. **P1-059 — `elapsed_ms` is observed call-to-result time, not `totalDurationMs`.**  
   Copying an existing duration field is an attractive rubber-stamp implementation, but it violates the user-visible timing contract and hides waits.

5. **P1-103 — Real downgrade round trip with the actual 1.1.7 release.**  
   A same-version migration unit test cannot reveal that Release N writes cache state which crashes or corrupts behavior in the previous release.
