# pr-assets

This branch holds the images that pull request descriptions link to, such as the before and after screenshots of a UI change. It shares no history with `main`, and nothing here is part of the app.

- Each pull request has its own folder, `pr-<number>/`.
- Link an image as `https://github.com/rpeck/claude-explorer/raw/pr-assets/pr-<number>/<file>.png`.
- Every screenshot comes from the e2e fixtures, never from real conversations.
